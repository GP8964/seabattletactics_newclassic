# Sea Battle Tactics
## A tribute to Navy Blue game series developed by Use Corporation on Game Boy and Famicom.

This is an attempt to remake the Navy Blue '98 version.

### Core Battleship Rules
Players take turns firing attacks onto a grid to locate, hit, and sink the opponent's hidden fleet of ships.

### Difference from the original game
In original game, you progress and unlock more ships and credits. In this remake, the settings of the last stage is used.
Original game was in Japanese only. This remake includes English and Japanese.

### Current progress
Finished the first prototyping in HTML, CSS and JavaScript. Currently it is single player only.

### Plans
1: Port the project to React and Express (Node.js front-end and back-end).
2: Make a 2 player version so that players can test their skills with each others.
3: The computer player only uses random single attacks for now, but in the future it will be replaced by a more intelligent AI with 60 credits, same as the human player.
4: I will also attempt to make this project compatible with multiple database management systems.
5: More languages will be supported in the future after satisfactory progress.

### Disclaimer
I had not reused their animations, weapon sprites. I had not reverse engineered any part of the original ROM of the game, ensured that this is a clean-room engineering.
