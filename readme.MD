# Sea Battle Tactics
## A tribute to Navy Blue '98 published by Shouei Systems (ショウエイシステム) on Game Boy

This is an attempt to remake a strategy game Navy Blue '98, published by Shouei Systems (ショウエイシステム) on Game Boy.

### Core Battleship Rules
Players take turns firing attacks onto a grid to locate, hit, and sink the opponent's hidden fleet of ships.

### Difference from the original game
In original game, you progress and unlock more ships and credits. In this remake, the settings of the last stage is used.
Original game was in Japanese only. This remake includes English and Japanese.
I do not reuse their animations, weapon sprites, and reverse engineer any part of the GB ROM, ensured that this is a clean-room engineering.

### Current progress
Finished the first prototyping in HTML, CSS and JavaScript. Currently it is single player only.

### Plans
Port the project to React and Express (Node.js front-end and back-end).
Make a 2 player version so that players can test their skills with each others.
I will also attempt to make this project compatible with multiple database management systems.
